**مشاور:** علی بهمن‌زاده
**دوره:** از ابتدای اردیبهشت ۱۴۰۵ تا پایان روز ۲۴ مهر ۱۴۰۵

**منبع داده:** دو جلد آرشیو RAR در ریشهٔ مخزن (`CamScanner 10-17-26 20.43.part1.rar` و `.part2.rar`)

## ۱. نکتهٔ بسیار مهم دربارهٔ آرشیوها

دو فایل RAR موجود در ریشهٔ مخزن، **دو جلدِ یک مجموعهٔ RAR5 هستند، نه دو آرشیو مستقل.**
بنابراین به‌هیچ‌وجه نباید با هم الحاق (concatenate) شوند. استخراج باید از `part1` آغاز شود؛
کتابخانهٔ استخراج به‌طور خودکار `part2` را دنبال می‌کند. حاصل استخراج، **یک** فایل PDF
۳۲ صفحه‌ای است:

```
source/extracted/CamScanner 10-17-26 20.43.pdf   (۳۲ صفحه، ۳۳.۴ مگابایت، بدون لایهٔ متن)
```

این فایل (و تصاویر استخراج‌شده از آن) به‌دلیل حجم بالا در مخزن ثبت نشده است؛ برای بازتولید،
دستورهای بخش ۵ را اجرا کنید.

## ۵. بازتولید خروجی‌ها

پیش‌نیازها: Python 3.11 با `pymupdf`, `reportlab`, `arabic-reshaper`, `python-bidi`,
`pillow`, `openpyxl`, `python-docx`؛ و Node.js با `node-unrar-js@2` برای استخراج آرشیو.

```bash
export PROJECT_ROOT=$PWD/project

# ۱) استخراج آرشیو (فقط از part1؛ part2 خودکار دنبال می‌شود)
node project/scripts/extract.js \
  "../../CamScanner 10-17-26 20.43.part1.rar" \
  "$PROJECT_ROOT/source/extracted"

# ۲) تصاویر تمام‌وضوحِ هر صفحه + نمایه
python3 project/scripts/extract_pages.py        # → processing/normalized_images

# ۳) خروجی‌های گزارش (PDF، Word و متن منبع)
python3 project/output/build_report.py          # → output/final_consultant_report.pdf
python3 project/output/build_text_outputs.py    # → report_source.md و .docx

# ۴) بازبینی خودکارِ خروجی (سرریز، تداخل نوشتار، حاشیه، قلم، واژگان کلیدی)
python3 project/output/validate_report.py       # کد خروجی ۰ = بدون نقص
```

## ۶. بازبینی کیفیت خروجی

`output/validate_report.py` پیش از تحویل روی هر ۴ صفحه اجرا می‌شود و این موارد را بررسی می‌کند:

- تعداد صفحات برابر ۴ و قلم Vazirmatn درون‌نشانی‌شده؛
- نبودِ خروجِ متن از حاشیه‌های تعیین‌شده (بالا، پایین، چپ و راست)؛
- نبودِ تداخلِ نوشتار (بررسیِ جعبه‌ایِ تک‌تک رشته‌های متن)؛
- نبودِ متنِ روشن روی زمینهٔ روشن (متن ناخوانا)؛
- نبودِ نشتِ چاپ به نوارهای حاشیهٔ کناری؛
- حضورِ واژگان و ارقام کلیدی در متنِ استخراج‌شده.
