# آرشیوهای منبع

## ۱) سند ۳۲ صفحه‌ای (CamScanner)

دو آرشیو منبع در **ریشهٔ مخزن** قرار دارند و در این پوشه تکرار نشده‌اند:

```
CamScanner 10-17-26 20.43.part1.rar   26,214,400 بایت
CamScanner 10-17-26 20.43.part2.rar    8,635,888 بایت
```

### هشدارِ مهم

این دو فایل، **دو جلدِ یک مجموعهٔ RAR5** هستند، **نه دو آرشیو مستقل.**

- آن‌ها را با هم الحاق (concatenate) نکنید؛
- استخراج باید از `part1` آغاز شود (کتابخانهٔ استخراج، `part2` را خودکار دنبال می‌کند)؛
- حاصل استخراج **یک** فایل PDF با ۳۲ صفحه است، نه دو فایل جداگانه.

قالب فایل‌ها RAR5 است (نه ZIP)؛ بنابراین `unzip` روی آن‌ها کار نمی‌کند.

### بازتولید

```bash
node project/scripts/extract.js \
  "CamScanner 10-17-26 20.43.part1.rar" \
  "project/source/extracted"
```

## ۲) آرشیو هشت‌بخشی تصاویر گزارش

تصاویر پیوست از آرشیو هشت‌جلدی زیر در **ریشهٔ مخزن** استخراج می‌شوند (مجموعاً ۲۲۲ مگابایت):

```
عکس های گزارش.part01.rar … part08.rar     → 63 فایل JPG در پوشهٔ «عکس های گزارش»
```

این هم یک مجموعهٔ **RAR5 چندجلدی** است؛ استخراج فقط از `part01` آغاز می‌شود.

```bash
unrar x "عکس های گزارش.part01.rar" project/source/photos_original/
```

تصاویر خام (۲۰۰ مگابایت) در `.gitignore` هستند؛ نسخهٔ بهینه‌شدهٔ آن‌ها (حداکثر ۱۲۰۰ پیکسل،
~۱۰ مگابایت) در `project/assets/photos/` نگهداری و در PDF جای‌گذاری می‌شود.
